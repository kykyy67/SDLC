## Описание
Учебное desktop-приложение, реализующее конвертер единиц измерения длины. Программа предоставляет удобный графический интерфейс для точного перевода значений между различными физическими величинами. Проект разработан на языке Java с использованием библиотеки компонентов Swing и строго следует архитектурному паттерну MVC (Model-View-Controller).

## Возможности
* Выбор исходной и целевой единиц измерения длины.
* Строгая валидация вводимых данных через диалоговые окна (защита от некорректного ввода).
* Расчет результата на основе заложенных коэффициентов конвертации.
* Графический интерфейс с кастомизированными элементами управления (скругленные кнопки).

## Технологии и архитектура
* **Язык программирования:** Java
* **Графический интерфейс:** Java Swing
* **Паттерн проектирования:** MVC (Model-View-Controller) + Observer
* **Среда разработки:** IntelliJ IDEA
